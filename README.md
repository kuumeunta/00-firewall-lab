# firewall-lab
Установка и настройка межсетевого экрана в локальной виртуальной сети.

# Устройства 
- Хост: Windows 10, VirtualBox 7.2.22
- VM1: Ubuntu 25.04, имя UbuntuMain, IP 192.168.56.101
- VM2: Ubuntu 25.04, имя UbuntuSub, IP 192.168.56.102
- Сеть: Host-Only
